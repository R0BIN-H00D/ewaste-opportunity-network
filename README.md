# E-Waste-to-Opportunity Network

Web (React/MERN) + Android (Flutter) platform that turns e-waste into repair, reuse, refurbishment, donation and responsible-recycling opportunities. **One Node/Express backend and one MongoDB database** serve both apps. Free APIs and open-source tools only.

| Folder | What |
|---|---|
| `backend/` | Node.js + Express + Mongoose REST API (+ Socket.IO from Phase 8) |
| `web/` | React + Vite + Tailwind web app |
| `mobile/` | Flutter Android app |
| `docs/` | `requirements.md`, `design.md`, `tasklist.md`, `claude.md`, setup/API/DB docs |
